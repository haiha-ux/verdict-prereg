## (6) Proposition 4: correct
Proof re-derived: consistency gives z_i >= z_j - 2e - L(t_j - t_i), hence upper end of C_i >= z_j - e + L(t - t_j); symmetric for lower; so I(t) contains [z_j+e-L a, z_j-e+L a], a = t - t_j. Numerical check: 143,389 random consistent L-Lipschitz/noisy instances (j=1..6 nodes) + 40,361 adversarial consistent z with random L, e: 0 violations. Nits: closed shrunk interval vs half-open [lo,hi) at one endpoint (measure zero); the bound is vacuous when L*age < e, i.e. age < e*fps/L = 1.3 frames, and "near-optimal" needs L*age >> e, i.e. only for ages of a few frames and up (2e band = 2.6 frames of cone width at the dev constants); that is exactly the m=8/16 regime but not m=2. Conditional on data consistency with the stated (e, L): on fresh data the dev constants are exceeded frame-wise (see 2), although the node-level cones were never empty (empty fraction 0 for m=8,16).
