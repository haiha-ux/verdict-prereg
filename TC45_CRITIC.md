## (1) Theorem 3 (theory/94 sec 8, lines 41-45): proof VALID, classical, 4 wording gaps
- Subset direction correct (|s(t)-z_i| <= L|t-t_i| + e). Superset: difference-constraint system with reference node 0 is correct; sup v = shortest path 0 -> v (Bellman-Ford / difference-constraints duality). Direct-path argument correct (path 0->y_j->y_i->v costs z_j+e+L|t_j-t_i|+L|t_i-t| >= z_j+e+L|t-t_j| by triangle). Nonempty: z_i-z_j <= 2e+L|t_i-t_j| <= 2e+L(|t-t_i|+|t-t_j|), so max-lower <= min-upper. Piecewise-linear extension through sorted points with slopes <= L is L-Lipschitz (named "McShane"; any Lipschitz extension works).
- Gaps (cosmetic, not errors): (i) "no negative cycle by consistency" is one clause: cycles through 0 are 0->y_a->...->y_b->0 = 2e + L*path - (z_b - z_a) >= 2e + L|t_a-t_b| - (z_b-z_a) >= 0 (pairwise consistency + triangle); cycles through v reduce by triangle; say so. (ii) "exactly the interval" needs convexity of the feasible set (linear constraints) to get all values between max and min; not stated. (iii) The corollary "abstains iff tau in I(t)" must read abstain iff lo <= tau < hi: with y = 1[s > tau] and tau = hi the answer is determined (0). Measure-zero, but "to the letter". (iv) The theory is for k = 1 only; section 3 Conjecture 3 (general k) stays unproved and the k >= 2 attainable set is not a plain interval intersection (LP / Micchelli-Rivlin); do not extend "optimal sound rule" to k >= 2.
- Causal corollary VALID: the same proof on the past nodes gives the attainable set given past observations; any sound causal rule must abstain when tau in it.
- Role of e: it is a per-sample bound on z_i - s(t_i) of the LATENT s; tests use e = max |z - SavGol(9,3)(z)| on dev_calib (tc_cert.py:25-31) and L = max |SavGol(21, order 3, deriv 1)| (tc2_cert.py:30), a 21-frame (1.05 s at 20 fps, 1.4 s at 15 fps) derivative filter that flattens sub-second transitions. These are empirical proxies, not validated bounds of s. Consistency passes largely through the e slack: 2e = 8.5/10.2/4.9 logit units vs z range ~ 30/32/21 (2e is 28-32% of the range).
- TARGET MISMATCH (WARN): Theorem 1/3 are about y(t) = 1[s(t) > tau]; tests 3-5 score against r_t = 1[z_t > tau] with z_t = s + eps_t. For r_t a sound enclosure needs radius 2e + L*age (target frame noise), the code uses e + L*age. So "error vs reader target" is not the Theorem-1 error, and no test so far evaluates soundness for the latent state (unobservable). Previous critic: 0 errors at ratio >= 1; that is empirical slack, not theory.
- NEW LEMMA the doc lacks (derived, verified numerically): causal intersection gain over the NEWEST node's cone is at most 2e per side and is nonzero only if z_j - z_i > L(t_j - t_i) for some older i (upper side: upper_j - upper_i = z_j - z_i - L(t_j - t_i) <= 2e by consistency). With L = max slope (q = 1.0) this is rare. Sec 8's "never less informative" is true but its size is ~0 in the tested regime.
