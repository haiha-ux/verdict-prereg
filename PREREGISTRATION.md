# VERDICT pre-registration v1 — label-free threshold re-setting under image shift, and the label cost of auditing a proposed threshold
Author: Hà Phan Thanh Hải (HCMUT); supervisor: Assoc. Prof. Dr. Quan Thanh Tho. Date of this version: 2026-10-27. Status: REGISTERED PUBLICLY ON GITHUB (release timestamp) and archived on the Wayback Machine; an OSF registration may follow and would reference this file's SHA-256. No logit, feature or probe output has been computed on any dataset listed in section 2 (confirmatory or pre-registered exploratory) at the time of this version.

## 1. Question
When a frozen linear probe on foundation features meets image shift, (a) when does label-free threshold re-setting help, and (b) how many audit labels does a valid error bound need if a label-free proposal is audited rather than a threshold learned from labels?

## 3. Reader, shifts, rules
Reader: DINOv2-small CLS + mean-patch features, logistic probe trained on the development split (regularisation C chosen on its calibration split). Shifts: the natural shift available in each dataset (RBO: the annotated light/background/camera conditions; BEHAVIOR-1K: none beyond the episode) and a fixed corruption grid: families gamma, rotate, occlude, jpeg, saltpepper, blur, noise, lowres, contrast, colour at 3 severities each (operators and parameters of H113/H119 unchanged).
Rules (label-free unless stated): R0 development threshold; Q quantile matching to the development predicted-positive rate; Otsu; oracle (uses evaluation labels; reference only).
Audit strategies (m labelled frames from the audit pool, m in {20, 50, 100, 200}): QA audit of Q; R0A audit of R0; LA choose the threshold on m/2 labels then audit on m/2 (cross-fitted variant also reported); BA-full audit both Q and R0 on all m labels at level alpha/2 and report the smaller one-sided Clopper-Pearson 95% bound. Truth = error of the chosen threshold on the disjoint evaluation pool.

## 4. Hypotheses (decided before data; each with a falsifier)
C1 Label-free repair is not universal: in natural-shift cells, mean error(Q) is lower than mean error(R0) by >= .01 in at least 2 of the analysed datasets. Falsified if it holds in at most 1.
C2 Ranking-conditional benefit: pooling cells, the share of the R0-oracle error gap recovered by Q is at least .20 higher in cells with AUC >= .9 than in cells with AUC < .9 (cluster bootstrap over dataset x operator family, lower bound of the 95% interval > 0). Falsified otherwise.
C3 Union-bound audit saves labels: at m = 100, the BA-full bound is lower than the LA bound by >= .02 in at least 3 of the analysed datasets (cluster bootstrap lower bound > 0 in each counted dataset). Falsified otherwise. (With only two Tier 2 datasets C3 cannot be satisfied by construction; it is evaluated descriptively.)
C4 Validity: for every strategy, dataset and m, the fraction of draws with truth <= bound is >= .95 on the disjoint evaluation pool. A single dataset below .95 is a reported failure of validity, not dropped.
Descriptive only: bound width curves, smallest m reaching a bound <= .10, the differential-shift statistic D and excess error, phase-only baseline accuracy.

## 5. Analysis plan and controls
Estimands: mean error per rule; recovery = (err(R0) - err(Q)) / (err(R0) - err(oracle)), cells with gap < .01 excluded and counted. Inference: bootstrap over clusters (dataset, operator family), B = 2000; the number of effectively independent cells is reported next to every interval. Multiplicity: Holm over C1-C4. No test-set peeking: no parameter, threshold or exclusion rule changes after the first evaluation-pool logit is computed; deviations go to a dated, append-only amendment log. Seeds fixed. Scripts for the new datasets do not exist yet: their SHA-256 will be appended in a dated amendment BEFORE any feature or logit of these datasets is computed; the hashes of the existing analysis code (experiments/e1_run.py 80ddfd0c8e9a4e253708fc30900013fd662f419cab7cb92ea1faa27f761ed060, experiments/e3_run.py f763ef6c90300bb3d9ae90c83584aa66c001d6ad2dc4536064f62316446b730e, theory/66_e3_design.md 63dd77e766a097cd03936450ff5a14682d99417d57ad30d0fd2fb674cdb996c8, theory/63_identification_robustness.md c5f43c40e86b2a8ab3a381e0c6adea68cf2194d954efb2478d25537b6068ba71) are recorded as the base.
